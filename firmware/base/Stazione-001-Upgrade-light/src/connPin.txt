SCL	GPIO5	bus I2C condiviso
SDA	GPIO4	bus I2C condiviso

BMP580 resistenze: 4,7kOhm * 2 per I2C
SHT45 resistenze: rilevate multimetro: 6,33/36kOhm * 2 per I2C
VEML7700 no resistenze per I2C
MCP9808 no resistenze per I2C
AS3935 no resistenze per I2C

Parallelo pull-up effettivo: SDA ≈ 2.7kOhm, SCL ≈ 4.2kOhm (BMP580 + SHT45; gli altri non contribuiscono)

=== BUS I2C PRINCIPALE (SDA=GPIO4, SCL=GPIO5) ===
(Solo sensori ambientali stabili: SHT45, MCP9808, VEML7700)

SHT45 (umidità):
  SCL   -> GPIO5
  SDA   -> GPIO4
  VCC   -> 3.3V
  GND   -> GND
  (indirizzo fisso 0x44)

VEML7700 (luce):
  SCL   -> GPIO5
  SDA   -> GPIO4
  VCC   -> 3.3V
  GND   -> GND
  3Vo   -> NC
  (indirizzo fisso 0x10)

MCP9808 (temperatura):
  SCL   -> GPIO5
  SDA   -> GPIO4
  A0,A1,A2 -> GND (indirizzo 0x18)
  VCC   -> 3.3V
  GND   -> GND
  ALERT -> NC

=== BUS SPI CONDIVISO (SCK=GPIO17, MISO=GPIO16, MOSI=GPIO15) ===

BMP580 (pressione):
  SCL   -> GPIO5
  SDA   -> GPIO6
  SDO   -> 
  INT   -> NC
  VCC   -> 3.3V
  GND   -> GND

Scheda MicroSD:
  SCK   -> GPIO17
  MISO  -> GPIO16
  MOSI  -> GPIO15
  CS    -> GPIO18 (CS dedicato)
  VCC   -> 3.3V
  GND   -> GND

AS3935 (fulmini) - sullo stesso bus fisico della SD:
  SCK   -> GPIO17
  MOSI  -> GPIO15
  MISO  -> GPIO16
  CS    -> GPIO9 (dedicato)
  SI    -> GND     (fissa modalità SPI)
  A0    -> GND
  A1    -> GND
  EN-VREG -> 3.3V
  IRQ   -> GPIO7 (interrupt rilevamento)
  VCC   -> 3.3V
  GND   -> GND

=== ALTRO ===

RGB LED (stato connessione) -> GPIO48

=== RIEPILOGO GPIO OCCUPATI ===

GPIO4  -> I2C SDA
GPIO5  -> I2C SCL
GPIO7  -> AS3935 IRQ
GPIO9  -> AS3935 CS
GPIO15 -> SPI MOSI (SD, BMP580, AS3935)
GPIO16 -> SPI MISO (SD, BMP580, AS3935)
GPIO17 -> SPI SCK  (SD, BMP580, AS3935)
GPIO18 -> SD CS
GPIO48 -> RGB LED
