SCL	GPIO5	bus I2C condiviso
SDA	GPIO4	bus I2C condiviso

BMP580 resistenze: 4,7kOhm * 2 per I2C
SHT45 resistenze: rilevate multimetro: 6,33/36kOhm * 2 per I2C
VEML7700 no resistenze per I2C
MCP9808 no resistenze per I2C
AS3935 no resistenze per I2C

Parallelo pull-up effettivo: SDA ≈ 2.7kOhm, SCL ≈ 4.2kOhm (BMP580 + SHT45; gli altri non contribuiscono)

=== BUS I2C CONDIVISO (SDA=GPIO4, SCL=GPIO5) ===

BMP580 (pressione):
  SCL   -> GPIO5
  SDA   -> GPIO4
  CS    -> 3.3V   (fissa modalità I2C, NON lasciare flottante/GND)
  SDO   -> GND    (indirizzo 0x46)
  INT   -> non collegato (polling, non serve)
  VCC   -> 3.3V
  GND   -> GND

SHT45 (umidità):
  SCL   -> GPIO5
  SDA   -> GPIO4
  VCC   -> 3.3V
  GND   -> GND
  (indirizzo fisso 0x44, nessun pin di selezione)

VEML7700 (luce):
  SCL   -> GPIO5
  SDA   -> GPIO4
  3Vo   -> non collegato (è un'uscita del regolatore interno, non un ingresso)
  VCC   -> 3.3V
  GND   -> GND
  (indirizzo fisso 0x10, nessun pin di selezione)

MCP9808 (temperatura):
  SCL   -> GPIO5
  SDA   -> GPIO4
  A0    -> GND
  A1    -> GND
  A2    -> GND    (indirizzo 0x18 con tutti a GND)
  ALERT -> non collegato (opzionale, serve solo per interrupt su soglia temperatura)
  VCC   -> 3.3V
  GND   -> GND

AS3935 (fulmini):
  SCL      -> 12 funge da clock
  MOSI     -> 11
  MISO     -> 13
  CS       -> 3.3V    (disattiva modalità SPI)
  SI       -> 3.3V    (seleziona modalità I2C: SI=GND sarebbe SPI)
  A0 (I0)  -> GND
  A1       -> GND     (indirizzo 0x03 con entrambi a GND)
  EN-VREG  -> 3.3V    (abilita regolatore interno, obbligatorio)
  IRQ      -> GPIO6   (interrupt dedicato, da gestire via attachInterrupt — evento raro/imprevedibile, non va a polling)
  VCC      -> 3.3V
  GND      -> GND

=== SCHEDA MicroSD (SPI dedicato, già presente nel firmware) ===

  MISO (SPI_MISO)  -> GPIO16
  CLK  (SPI_CLK)   -> GPIO17
  MOSI (SPI_MOSI)  -> GPIO15
  CS   (chipSelect) -> GPIO18
  VCC              -> 3.3V
  GND              -> GND

=== ALTRO ===

RGB LED (stato connessione) -> GPIO48

=== RIEPILOGO GPIO OCCUPATI ===

GPIO4  -> I2C SDA (BMP580, SHT45, VEML7700, MCP9808, AS3935/MOSI)
GPIO5  -> I2C SCL (BMP580, SHT45, VEML7700, MCP9808, AS3935)
GPIO6  -> AS3935 IRQ
GPIO15 -> SD SPI MOSI
GPIO16 -> SD SPI MISO
GPIO17 -> SD SPI CLK
GPIO18 -> SD SPI CS
GPIO48 -> RGB LED

Nessuna collisione tra bus I2C, SPI SD e IRQ fulmini.
